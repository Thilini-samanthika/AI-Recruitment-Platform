# Company Service (Member 3)

Port: `8083`  
Database: `company_db` (MySQL)  
Gateway Path: `/api/companies/**`

## Endpoints to implement:
- `GET /api/companies/profile` - Get company profile
- `POST /api/companies/profile` - Create / Update company profile
- `GET /api/companies/recruiters` - Manage company recruiters
- `GET /api/companies/analytics` - View applicant statistics
