# Frontend (Member 5)

Port: `3000`  
Stack: React.js / Next.js, TailwindCSS / Vanilla CSS  
Backend Gateway Target: `http://localhost:8080`

## Pages & Flows:
- `/login` & `/register` - Authentication forms talking to `http://localhost:8080/api/auth`
- `/candidate/dashboard` - Profile, resume upload, and application tracking
- `/company/dashboard` - Company profile, job posting, applicant evaluation
- `/jobs` - Job board and search
